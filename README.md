# 微信下载同步

一个 macOS 后台工具，将微信聊天中新接收的文件自动整理到系统“下载”文件夹，同时保留微信中打开文件所需的原路径。

微信仍先把文件写入自己的 `msg/file` 目录。程序发现新文件在约 15 秒内大小和修改时间没有变化后，将其移到“下载”，并在微信原位置建立指向该文件的符号链接。

## 功能

- 仅处理启用同步后在所选微信账号目录中新出现的普通文件，启用前的文件留在原处。
- 文件内容保存在“下载”中，微信原目录保留链接。
- 在“下载”中删除文件后，微信目录中的对应链接会自动移除。
- 在“下载”内改名或移入子文件夹后，微信链接会跟随更新。同名文件使用新名称保存。
- 使用 macOS LaunchAgent 在用户登录后运行，微信关闭时程序也会运行。

本项目是独立工具，与腾讯微信没有官方关联。

## 适用环境

- 构建目标为 macOS 13 或更新版本，包含 Apple 芯片和 Intel 架构。
- 已在 Apple 芯片、macOS 27.0.1、微信 4.1.15 上验证原始同步流程。Intel 架构已通过 Rosetta 运行模拟自测，尚未在 Intel 实机上验证。
- 适用于微信 4.x 使用 `xwechat_files/<账号>/msg/file` 的目录结构。一次安装绑定一个账号。
- 微信文件目录和系统“下载”文件夹需要位于同一文件系统。

## 安装

1. 从本项目的 Releases 下载 `WeChatDownloadSync-v0.1.0-macOS.zip` 并解压。
2. 保留解压出的整个文件夹，在访达中打开 `Install.command`。
3. 按提示选择微信账号的 `msg/file` 文件夹，再选择系统“下载”文件夹。
4. 终端显示“安装完成”后，后台程序会在当前会话启动，并在以后登录时自动启动。

微信账号目录通常位于下面的位置，可在选择窗口按 **Command + Shift + G** 后粘贴路径，再进入对应账号的 `msg/file` 文件夹。

```text
~/Library/Containers/com.tencent.xinWeChat/Data/Documents/xwechat_files
```

如果目录里有多个账号，请选择希望同步的账号。微信中的图片、视频、聊天记录数据库以及其他账号的数据由微信自行管理。

发行包使用本机构建的临时签名，尚未使用 Apple Developer ID 签名和公证。macOS 可能要求你在系统的“隐私与安全性”设置中确认打开。你也可以先审阅源代码并自行构建。

## 使用时需要了解

- 程序通过文件大小和修改时间判断文件是否稳定。如果下载中途暂停超过 15 秒，文件有可能提前被移动。
- 将文件移出“下载”文件夹时，微信目录中的链接会被移除。将文件从废纸篓恢复后，微信链接不会自动重建。
- 删除联动作用于“下载”中的文件和所选 `msg/file` 中的链接。微信自身可能维护单独的预览或其他缓存。
- 程序每约 2 秒检查一次微信文件目录。下载文件从原位置消失时，会检查“下载”目录以识别改名或移动。
- 如果已经运行其他针对同一账号目录的同步程序，请先停用它，避免两个程序同时操作同一文件。

## 权限与本地数据

安装时需要通过系统窗口授权所选的微信 `msg/file` 和“下载”文件夹。程序运行在 macOS 应用沙盒中，使用安全范围书签保存所选目录的访问权限，应用沙盒未启用网络访问权限。

程序在自己的应用容器中保存所选路径、已有文件清单和链接状态。运行日志位于 `~/Library/Logs/WeChatDownloadSync.log`，其中可能包含文件名。

## 卸载

打开发行包里的 `Uninstall.command`，即可停止并移除后台启动项和应用。已下载文件、微信目录中的链接以及本地配置数据会保留。

卸载后，现有链接继续指向“下载”中的文件。后续文件删除、改名和移动将由你自行管理。

## 从源代码构建

需要 Xcode Command Line Tools。执行以下命令后，通用架构发行包和 SHA-256 校验文件会出现在 `dist/`。

```bash
bash build.sh
```

运行模拟自测：

```bash
./build/WeChatDownloadSync-arm64 --self-test
```

Intel 电脑可运行 `./build/WeChatDownloadSync-x86_64 --self-test`。自测使用临时目录，覆盖新文件、已有文件、删除、同名、改名、移动及中断恢复等流程。

安装与卸载脚本的隔离模拟测试可通过 `bash test-install.sh` 运行。
